# Supreme Leather Industries — Premium Craftsmanship Hero

A single-screen, full-viewport landing hero experience for **Supreme Leather Industries**, a luxury leather goods and craftsmanship atelier.

Built with **React, TypeScript, Vite, GSAP, Framer Motion, and Lenis**, featuring warm sunlit editorial lighting, seamless edge blending, and frosted-glass craftsmanship cards.

## Features

- **Cinematic Hero Composition:** Artisanal hand rising with an intricately embossed burgundy leather belt and antique-metal buckle floating and revolving against warm sandstone walls and botanical shadows.
- **Dynamic Scale System:** Reference scaling based on a 2048×1152 artboard via `--s = min(100vw/2048, 100vh/1152)`.
- **Seamless Viewport Coverage:** Full-viewport background extension with soft gradient masking to eliminate empty vertical bars without cropping, stretching, or altering the video framing.
- **Glassmorphism Craftsmanship Cards:** Frosted warm ivory translucent cards with hairline borders and backdrop blur highlighting brand qualities (*Genuine Leather, Refined Detailing, Timeless Character*).
- **Responsive Navigation & Mobile Support:** Clean monogram identity, floating navigation header, and fluid mobile/tablet layouts with animated navigation drawer.
- **Micro-Interactions & Transitions:** Fluid entrance animations with GSAP and interaction feedback with Framer Motion.

## Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Animation:** GSAP (orchestrated entrance sequences) & Framer Motion
- **Smooth Scroll:** Lenis
- **Icons:** Lucide React
